# Chronicle v0.2.2 — fix v0.2.1 crash on first launch

Quick hotfix for the v0.2.1 release that shipped a few minutes earlier.

## What broke in v0.2.1

When v0.2.1 was installed via `brew install --cask chronicle` (or by downloading the .zip and dragging it in without stripping quarantine), the app crashed on first launch before the window appeared. The crash report pointed at `ProviderIconView.body.getter` calling `Bundle.module`, which asserted via `preconditionFailure` because `Bundle(url:)` returned nil for every candidate path under macOS app translocation. That's the security feature where macOS runs a quarantined `.app` from a randomized read-only location the first time it's launched from `/Applications`.

Once `Bundle.module` failed, `dispatch_once` latched the failure and every later access crashed too. The in-app `QuarantineDetector` card that v0.1.x added never got a chance to render and walk the user through the fix.

## Fix

`ProviderIconView` now resolves the brand-glyph PDFs by walking a list of candidate paths on disk via `FileManager` and `NSImage(contentsOf:)` instead of going through `Bundle.module`. A missing resource causes the view to fall through to the SF Symbol fallback that was already in the code, rather than asserting in an initializer.

Net behavior: the app launches even if `xattr -cr` was never run, the in-app quarantine card has a chance to show, and the icons still render correctly because the candidate paths cover the SwiftPM-bundled `Chronicle_Chronicle.bundle` layout.

## Upgrade

```bash
brew update
brew upgrade --cask chronicle
```

If you're already on v0.2.1 and have it running, the in-app `Check for updates…` will show v0.2.2 once the appcast is published. The Sparkle pipeline ships its first real update with this release.

If `brew upgrade` errors with "App source `/Applications/Chronicle.app` is not there" mid-upgrade, run:

```bash
brew uninstall --cask chronicle --force
brew install --cask chronicle
```

That clears any stale caskroom state from the v0.2.1 → v0.2.2 transition.
