# Chronicle v0.2.3 — fix Sparkle update-panel formatting

Cosmetic hotfix on top of v0.2.2. The app binary is byte-identical to v0.2.2; only the appcast renderer changed.

## What broke in v0.2.2's appcast

Sparkle's update panel renders `<description>` as **HTML**. The CI script that builds `appcast.xml` was embedding raw Markdown release notes, so users on v0.2.1 who clicked "Check for updates…" saw `# Chronicle v0.2.2`, `## What broke`, and the literal backticks inline instead of rendered headers and code spans.

## Fix

`emit-appcast.sh` now POSTs each release body through GitHub's `/markdown` endpoint (`gh api -X POST /markdown -f mode=gfm`) and embeds the resulting HTML in the appcast. Same renderer GitHub uses on the Releases page, so the in-app update panel now matches what you see on the web.

## Upgrade

You don't have to do anything special. Click `Check for updates…` from the Chronicle menu — Sparkle will offer v0.2.3 with properly formatted release notes. Hit Install Update and it swaps in place.
