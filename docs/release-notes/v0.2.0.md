# Chronicle v0.2.0 — multi-provider

Chronicle now reads Codex CLI and Gemini CLI history alongside Claude Code. One app, three providers, kept separate so a Codex pin doesn't end up under Claude.

## What's new

### Codex and Gemini support

Reads JSONL rollouts from `~/.codex/sessions/` and JSON files from `~/.gemini/tmp/<project>/chats/`. Switch with the segmented control in the title bar, the menubar tile grid (`⌘⇧O`), or the View menu. Switching swaps the workspace list, session counts, smart folders, stats, tags, and pins to the active provider's data.

The brand glyphs are the actual logos (Anthropic burst, OpenAI swirl, Google Gemini star), template-tinted so they pick up whatever theme you're on.

### Resume, routed per provider

Each CLI takes a different resume invocation, and the launcher gets each one right:

- Claude: `claude --resume <uuid>`
- Codex: `codex resume <uuid>` (subcommand, not a flag)
- Gemini: `gemini --resume <uuid>` (full UUID, not the numeric index)

The session's working directory is preserved.

### Transcript view for Codex and Gemini

Same view as Claude: message bodies, inline collapsible tool calls, real model names (`gpt-5.4`, `gemini-3-flash-preview`), Files Touched, Tools Used, TOC sidebar. Tool-only assistant turns no longer leave blank bubbles, which v0.1.x did.

### Search across all three

Title search and `/full:` FTS5 body search work on every provider. The active tab scopes the result set, so a Codex search returns Codex sessions only.

### Live indexing

Per-provider watchers detect new sessions and tail in-flight files. Switching providers runs a fast catch-up walk, so a session created while a watcher was inactive shows up within about five seconds. No restart needed.

### Sessions, tags, and pins are kept apart per provider

Every record (session, tag, pin, archive flag, custom title, note, smart folder) now carries a `provider` column. v0.1.6 records migrate to `provider=claude` automatically. iCloud sync preserves the tag end to end, so a Codex pin on Mac A doesn't show up under Claude on Mac B.

### UI polish

The provider segmented control now matches the Sessions/Stats tab style: a subtle elevation pop for the active button, no brand-color fill. That keeps it readable on every theme without depending on the accent's contrast. Brand SVGs come from claude.ai's favicon, Wikimedia's ChatGPT_logo, and Simple Icons' googlegemini, theme-tinted via `NSImage`.

## Compatibility

macOS 15 or newer. Universal binary (arm64 + x86_64), built against the macOS 26 SDK. The v0.1.6 schema upgrades on first launch in under two seconds; existing Claude data is preserved and not re-bootstrapped. v0.1.6 readers see v0.2.0 records as `provider=claude` and do not crash.

## Known wart

The "Resume in Ghostty" button triggers Ghostty's "Allow Ghostty to execute ..." dialog every time you click it. This is a Ghostty security gate ([discussion #10203](https://github.com/ghostty-org/ghostty/discussions/10203)) for externally-invoked commands and can't be turned off in config. iTerm, Terminal, WezTerm, Alacritty, and Kitty don't have this prompt.

## Install or upgrade

```bash
brew update
brew upgrade --cask chronicle
```

Or grab `Chronicle-0.2.0.pkg`, `.dmg`, or `.zip` from the assets below. SHA256 checksums are in `Chronicle-0.2.0.shasums`.
