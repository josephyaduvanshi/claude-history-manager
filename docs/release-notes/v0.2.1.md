# Chronicle v0.2.1 — in-app auto-update

Chronicle now updates itself. Click "Check for updates…" and if a new release is out, Chronicle downloads it, verifies an EdDSA signature against a public key embedded in the app, swaps the running bundle in place, and relaunches. No browser, no manual download, no sudo prompt.

## What's new

### Sparkle-driven auto-update

The v0.2.0 "Download → opens browser" flow is replaced by [Sparkle](https://sparkle-project.org). Each release zip is signed in CI with an EdDSA private key held only as a GitHub secret; the matching public key ships in the app. A tampered download fails verification and is rejected before it touches your `/Applications` folder.

Updates remain user-triggered. There is still no background polling and no daemon. The same outbound-call rule v0.1.x had still applies. The only thing that changed is what happens after you click the menu item: silent install instead of "download and drag".

## Migration note for v0.2.0 users

v0.2.0 doesn't have Sparkle, so this one upgrade is still manual. Grab `Chronicle-0.2.1.pkg` (or `.dmg`/`.zip`) from the assets below or run `brew upgrade --cask chronicle`. From v0.2.1 onward, all upgrades are one click.

## Known limitations

Without Apple Developer ID and notarization, macOS may show a "Chronicle was downloaded from the internet" warning on the first relaunch after a Sparkle update. Click "Open" once or run `xattr -cr /Applications/Chronicle.app` to clear it. Notarization is on the roadmap; once it lands, the warning goes away.

## Install or upgrade
